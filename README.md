# Newstensity landing page

Starter project built with Next.js App Router, TypeScript, Tailwind CSS v4, Lucide React, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the page.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
- `npm run typecheck` — check TypeScript types

## Structure

- `app/` — routes, layout, and global styles
- `components/` — reusable UI components
- `lib/` — place for shared utilities
